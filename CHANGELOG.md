# Changelog

All notable changes to `filament-range-field` will be documented in this file.

## 0.7.0 - 2026-10-06

What's New:

- Filament v5 support. Filament v4 is still supported (`^4.0|^5.0`).
- Fix `->live(onBlur: true)` and `->live(debounce: ...)` producing broken JavaScript. If you published the views, republish them to get this fix.
- Fix the slider thumb colour on Filament v4 and v5.

**Full Changelog**: https://github.com/clnt/filament-range-field/compare/0.6.0...0.7.0

## v0.3.0 - 2022-07-15

What's New:

- Allows float values in the min, max, and step properties #5
